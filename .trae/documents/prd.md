## 1. 产品概述

一个基于原生 HTML、CSS 和 JavaScript 构建的多页面导航网站，展示顶部导航栏的交互能力，包括菜单展开/折叠、hover 效果和当前页面高亮。目标用户为前端开发者，用于学习和演示原生 Web 开发中的导航交互模式。

## 2. 核心功能

### 2.1 功能模块

1. **首页**：Hero 展示区、特性介绍卡片
2. **关于页**：团队介绍、项目愿景
3. **联系页**：联系方式、留言表单

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | Hero 展示区 | 全屏视觉主图，标题和副标题动画入场 |
| 首页 | 特性卡片区 | 三列卡片展示核心特性，hover 浮起效果 |
| 关于页 | 团队介绍 | 团队成员头像和简介卡片 |
| 关于页 | 项目愿景 | 时间线式的发展历程展示 |
| 联系页 | 联系表单 | 包含姓名、邮箱、消息的表单，带输入验证 |
| 联系页 | 联系信息 | 地址、电话、邮箱信息展示 |
| 全局 | 顶部导航栏 | 桌面端横向菜单、下拉子菜单展开/折叠、hover 效果、当前页高亮 |

## 3. 核心流程

用户进入网站 → 通过顶部导航栏切换页面 → 当前页面菜单项高亮 → 点击含子菜单的菜单项展开/折叠下拉菜单 → 在各页面浏览内容

```mermaid
    "点击子菜单项" --> "跳转页面"
    "跳转页面" --> "高亮当前页菜单项"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深墨绿 `#1a2f23`，辅助色：暖金 `#c8a45c`，背景色：奶白 `#f5f0e8`
- 按钮风格：圆角、微阴影、hover 时光晕扩散
- 字体：Playfair Display（标题）+ DM Sans（正文）
- 布局风格：顶部固定导航、内容区居中、卡片式模块
- 图标风格：简约线条图标（纯 CSS/SVG 内联实现）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 首页 | Hero 展示区 | 全屏背景渐变，大标题 + 副标题，CTA 按钮，入场动画 |
| 首页 | 特性卡片区 | 三列网格卡片，hover 上浮 + 阴影加深，图标 + 标题 + 描述 |
| 关于页 | 团队介绍 | 头像圆形，姓名 + 职位，hover 时翻转展示简介 |
| 关于页 | 项目愿景 | 垂直时间线，年份 + 事件描述，滚动渐入动画 |
| 联系页 | 联系表单 | 输入框带浮动标签，提交按钮，focus 时边框变金色 |
| 联系页 | 联系信息 | 图标 + 文字列表，hover 时图标微动 |
| 全局 | 顶部导航栏 | 半透明毛玻璃背景，Logo 左侧，菜单右对齐，下拉菜单 slide-down 动画 |

### 4.3 响应式

- 桌面优先设计（≥1024px）：横向导航 + 下拉菜单
- 平板（768px-1023px）：横向导航，菜单项间距缩小
- 移动端（<768px）：汉堡菜单 + 侧滑菜单面板
